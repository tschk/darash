Search, fetch, extract.
The all-in-one research crate.

Darash does the whole research loop in one dependency: web search on an in-process multi-source backend, always-reporting page fetches, and deterministic HTML extraction shaped for a context window.

$ cargo add darash

One crate, the whole loop

No keys, no cloud, no per-call pricing. Everything runs in your process, capped and deterministic.

Search

let client = SearchClient::local()?;
let res = client
  .search_request(&req)
  .await?;

Provider-neutral, in-process multi-source backend by default, or point it at any SearxNG endpoint.

Fetch

let report = fetch
  .fetch(url, &[])
  .await?;
report.summary()

Never silent: status, final URL, redirects, timing, size, and body — even on error statuses. Bodies capped at 2 MiB.

Extract

let md = fetch
  .to_markdown(&body);
let rows = fetch
  .rows(&body, ".item",
    "title=h2")?;

Markdown, outlines, selector matches, multi-field rows, and tables — all local and deterministic.

The CLI ships with it

cargo install darash gives you a research binary, not just a library. Extraction prints data on stdout and a report on stderr; omissions are announced, never silent.

# search the in-process backend, get cited sources
darash search "rust async" --json

# read a page as markdown within a token budget
darash fetch https://example.com --md --budget 800

# discover structure, then extract rows
darash fetch https://example.com --outline
darash fetch https://example.com --select .item --row "title=h2, url=a@href"
