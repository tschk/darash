src/main.rs
use darash::{fetch, SearchClient, SearchRequest};
 
#[tokio::main]
async fn main() -> Result<(), darash::Error> {
    let request = SearchRequest::new("rust async");
    let response = SearchClient::local()?.search_request(&request).await?;
    for source in response.cited_sources() {
        println!("{}: {}", source.title, source.url);
    }
 
    let report = fetch::fetch("https://example.com", &[]).await?;
    println!("{}", report.summary());
    Ok(())
}

$ darash search

Provider-neutral async search. SearchClient::local() runs the in-process multi-source backend; SearchClient::new(endpoint) targets any SearxNG-compatible endpoint. No AI provider is called — results project into citations for the host to synthesize.

# modes

speed
Selects one provider and returns at most 5 results.
balanced (default)
Selects up to two providers and returns at most 10 results.
quality
Selects all requested providers and returns at most 20 results.

# sources

web (default)
Queries the hosted metasearch backend; plug in any SearxNG/websurfx instance.
academic
Queries OpenAlex works.
discussions
Queries Hacker News Algolia results.

Each selected provider contributes up to 5 results in speed and up to 10 in balanced or quality, before URL deduplication and relevance ranking. Every SearchResult carries its title, URL, content, engines, category, publication date, and score.

# cli

shell
# in-process backend, cited sources
$ darash search "rust async"
 
# pick a mode and a source
$ darash search "rust async" --mode quality --source academic
 
# point at another SearxNG-compatible endpoint
$ darash search "rust async" --url http://localhost:8080
 
# machine-readable results
$ darash search "rust async" --mode speed --json

$ darash fetch

Every fetch returns a FetchReport with the status, final URL, redirect flag, elapsed time, content type, size, and body — never silent, even for error statuses. Bodies are capped at 2 MiB. Extraction is local and deterministic.

# extraction

(default)
Full report as JSON, including the body.
--body
Print only the response body.
--md
Render the page as markdown.
--text
Render the page as plain text.
--outline
Show repeating structures found on the page.
--select CSS
Print text matches for a CSS selector.
--count
With --select, print just the match count.
--row "name=sel,url=a@href"
Extract multi-field rows from a repeating container named by --select.
--table
Extract keyed table rows.
--locate TEXT
Find the deepest element whose text or attribute contains TEXT; prints a CSS selector path and an 80-character snippet.

# pagination, filtering, output

--limit N
Caps a page of structured output. Default 50.
--offset N
Starts the page at N (structured output only).
--where EXPR
Filter --row / --table output with a safe expression language: == != ~ !~ > >= < <=, && / || / !, /regex/[flags], and backtick column names.
--budget N
Cut output at item boundaries to an estimated token budget (≈4 chars/token), always keeping at least one item.
--json
Wrap any mode as a data + meta envelope (status, ok, url, ms, bytes, count, omitted).
--json-envelope
Structured output as a paginated envelope (state, total, offset, returned, next_offset), where state is more, complete, or past_end.

Rows and a single table print as TSV by default; --json switches them to JSON rows, and multiple tables always print as JSON. Omissions and pagination are announced on stderr, never silent.

# curl reflexes

-X, --method M
Request method.
-d, --data BODY|@FILE|@-
Request body; @file and @- strip CR/LF.
--data-raw B
Body where @ is never read as a file.
--data-binary B
Body kept byte for byte.
-u USER:PASS
Basic auth.
-I, --head
HEAD request.
-o FILE
Atomic write to a file (default report or --body).
-k, --insecure
Accept invalid TLS certificates.
-m, --max-time SECS
Request timeout in seconds.
--max-bytes N
Override the 2 MiB fetch body cap.
--header 'Name: value'
Add a request header.
-f, --fail
HTTP error exits 22 after printing the report.
-L, -i, -s, -S
Accepted no-ops, for curl muscle memory.

# cache

(default)
Fetched URL bodies are cached ~2 minutes under the user cache dir and reused by parse modes. Cache hits announce their age on stderr.
--fresh
Refetch and re-cache, ignoring any cached body.
--no-cache
Never read from or write to the cache.

The cache is bypassed by custom headers, non-GET methods, request bodies, Cache-Control: no-store, and credential-bearing URLs.

# cli

shell
# full report, JSON (default)
$ darash fetch https://example.com
 
# markdown within ~800 tokens
$ darash fetch https://example.com --md --budget 800
 
# discover structure, then extract rows
$ darash fetch https://example.com --outline
$ darash fetch https://example.com --select ".item" --row "title=h2, url=a@href"
 
# filter rows, page them, wrap in an envelope
$ darash fetch https://example.com --select ".item" --row "title=h2, url=a@href" \
    --where 'title ~ /rust/' --limit 10 --offset 20 --json-envelope
 
# which selector holds this text?
$ darash fetch https://example.com --locate "Example Domain"
 
# curl reflexes + local files work too
$ darash fetch https://example.com -X POST -d @payload.json --header 'Content-Type: application/json'
$ darash fetch page.html --md --fresh

Limits: 15 s search timeout, 256 KiB search response cap, 2 MiB fetch body cap, queries ≤ 512 chars, http/https only, no embedded credentials.

# keys & limits

anonymous
No key needed: search + fetch at 30 requests/hour, 100/day per IP. That is the only limit an IP ever hits.
free key
Unmetered search + fetch, plus batch (cap 20) and background async jobs. Ask for one — keys pass as Authorization: Bearer dk_…
pro key
Everything free has, a batch cap of 45, and /api/research: a search that fetches the top pages and returns a per-source markdown corpus.

Keys are never rate-limited — only anonymous traffic is. Check GET /api/account for your usage snapshot. Rate-limit responses carry Retry-After.
